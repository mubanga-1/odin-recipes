# Odin-recipes

Made to revise html and css basics covered within the odin project. Covers writing html boilerplate, basic tags such as lists, images, divs, links, formatting tags (i.e. strong, i), headers, sections and line break tags.

Contains use of basic css in order to change default text colors, margins, padding and box sizing.

## What I gained 

- Revision of html basic tags
- Revision of simple postioning and layouts in css
- Revision of html file creation taking into consideration the css styles to applied later on.
